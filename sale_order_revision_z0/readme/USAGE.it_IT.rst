Quando un ordine è annnulato, appare il bottone [Nuova copia preventivo] che
cree una nuova revisione del preventivo con lo stesso numero di base e il suffisso
di revisione.

Nella vista forma, una nuova tab è aggiunta con la lista delle precedenti revisioni,
con la data in cui furono dichiarate obsolete.

Le vecchie versioni sono inattive e quindi come se fossero inesistenti.
