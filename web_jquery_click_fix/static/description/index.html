Fix delegated click events on recent browsers (Chrome 89+)

Corregge gli eventi click delegati sui browser recenti (Chrome 89+)

Unknown description_img

Since Chrome 89, browsers set event.button on click events in a way that the jQuery 1.11.1 shipped with Odoo 10 does not expect: some delegated clicks are dropped and buttons or links in the web client do not respond.

This module loads a patched copy of jQuery 1.11.1 instead of the standard one. The only change is the delegated-event check in jQuery.event.handlers. The module is installed automatically together with web.

Da Chrome 89, i browser impostano event.button sugli eventi click in un modo non previsto da jQuery 1.11.1 incluso in Odoo 10: alcuni click delegati vengono persi e pulsanti o link del client web non rispondono.

Questo modulo carica una copia corretta di jQuery 1.11.1 al posto di quella standard. L'unica modifica è il controllo degli eventi delegati in jQuery.event.handlers. Il modulo si installa automaticamente con web.
