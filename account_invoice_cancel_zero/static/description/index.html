Set account invoice, if amount zero, to open (unpaid)

Riporta una fattura, di importo 0 e pagata, allo stato aperto (non pagato)

Unknown description_img

When an invoice with zero amount is validated, Odoo set it as paid. This is very useful but sometimes this invoice have to be updated and it is not possible because invoice is paid. This modulo can set paid invoice with zero amount to state open (unpaid), so it is possible to ste in draft mode and update it.

Quando una fattura con importo pari a zero viene convalidata, Odoo la imposta come pagata. Questo è molto utile, ma a volte questa fattura deve essere modificata e non è possibile perché è pagata. Questo modulo può impostare una fattura pagata con importo pari a zero come aperta (non pagata), in modo da poterla impostare in modalità bozza e modificarla.
