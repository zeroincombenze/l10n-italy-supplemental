Print dates as dd-mm-yyyy in the customer overdue report

Stampa le date come gg-mm-aaaa nel report scaduto cliente

Unknown description_img

The standard customer overdue report (Customer account statement) prints dates in the raw yyyy-mm-dd format.

This module prints the report date, the entry dates and the due dates as dd-mm-yyyy. Empty due dates are printed blank.

Il report standard dello scaduto cliente (Estratto conto cliente) stampa le date nel formato grezzo aaaa-mm-gg.

Questo modulo stampa la data del report, le date di registrazione e le date di scadenza nel formato gg-mm-aaaa. Le date di scadenza vuote sono lasciate in bianco.
