SEPA Direct Debit CBI file (Italy) for payment orders

File SDD CBI (Italia) per le distinte di incasso

Unknown description_img

Italian banks accept SEPA Direct Debit collections in the CBI format (CBISDDReqLogMsg) instead of the standard ISO 20022 pain.008 file. This module adds two payment methods to the OCA payment orders:

  • Sepa Direct Debit CORE ITA-CBI: debits to consumers (CORE scheme)
  • Sepa Direct Debit B2B ITA-CBI: debits to businesses (B2B scheme)

A debit payment order using one of these methods generates the CBI file, ready to be uploaded to the home banking.

The file is created by the Python library fintech.

Le banche italiane accettano gli incassi SEPA Direct Debit nel formato CBI (CBISDDReqLogMsg) invece del file standard ISO 20022 pain.008. Questo modulo aggiunge due metodi di pagamento alle distinte OCA:

  • Sepa Direct Debit CORE ITA-CBI: addebiti a consumatori (schema CORE)
  • Sepa Direct Debit B2B ITA-CBI: addebiti a imprese (schema B2B)

Una distinta di incasso con uno di questi metodi genera il file CBI, pronto per essere caricato sull'home banking.

Il file è creato dalla libreria Python fintech.

Configuration | Configurazione

  • Company: set the SEPA Creditor Identifier and the Initiating Party Identifier, which is the CBI unique code (CUC, 8 letters or digits). Both can be overridden on the payment mode.
  • Bank journal: add the payment method Sepa Direct Debit CORE ITA-CBI or Sepa Direct Debit B2B ITA-CBI to the incoming payments.
  • Payment mode: create a mode with one of the methods above and the bank journal.
  • Customer: the bank account needs a valid IBAN and the bank a BIC code; create a valid mandate with the same scheme (CORE or B2B) as the method.

If a module providing wallet accounts ("conto di portafoglio") is installed, the main bank account of the wallet is written in the file as creditor.

  • Azienda: impostare il Codice Identificativo del Creditore e l'Identificativo della parte iniziante, cioè il codice univoco CBI (CUC, 8 lettere o cifre). Entrambi possono essere ridefiniti nel modo di pagamento.
  • Registro banca: aggiungere il metodo Sepa Direct Debit CORE ITA-CBI o Sepa Direct Debit B2B ITA-CBI ai pagamenti in entrata.
  • Modo di pagamento: creare un modo con uno dei metodi sopra e il registro banca.
  • Cliente: il conto bancario deve avere un IBAN valido e la banca il codice BIC; creare un mandato valido con lo stesso schema (CORE o B2B) del metodo.

Se è installato un modulo che gestisce i conti di portafoglio, nel file viene scritto come creditore il conto principale del portafoglio.

Usage | Utilizzo

  • Validate the customer invoices with the SDD CBI payment mode.
  • Accounting › Payments › Debit Orders: create the order, or use Add to Debit Order on the invoices.
  • Confirm the order and press Generate Payment File: the CBI XML file is attached to the order.
  • Upload the file to the home banking, then press File Successfully Uploaded.

  • Validare le fatture cliente con il modo di pagamento SDD CBI.
  • Contabilità › Pagamenti › Ordini di addebito: creare l'ordine, oppure usare Aggiungi a ordine di addebito dalle fatture.
  • Confermare l'ordine e premere Genera file di pagamento: il file XML CBI viene allegato all'ordine.
  • Caricare il file sull'home banking, quindi premere File caricato con successo.
