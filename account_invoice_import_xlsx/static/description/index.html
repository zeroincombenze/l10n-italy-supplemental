Import invoice from Excel file

Importa fatture da file Excel

Unknown description_img

This module imports invoice data from an Excel (.xlsx) file in two ways:

  • Import lines into an invoice: the button  Import xlsx  on a draft invoice or vendor bill adds one line per row of the file. Products are searched by code and name; price, account and taxes come from the product unless the file supplies them.
  • Create invoices: the menu Accounting › Configuration › Import Account Invoice creates draft invoices. A row with customer data starts a new invoice; rows without customer data add lines to it.

Recognized column titles:

  • Denominazione Cliente: Partner name
  • Partita Iva: Partner VAT number (IT is added to digits only)
  • Codice Fiscale: Partner fiscal code
  • Codice: Product code
  • Nome: Line description
  • Quantita: Quantity
  • Imponibile: Taxable amount (line with quantity 1)
  • Iva: Tax amount; nearest rate among 0, 4, 5, 10, 22% is used
  • Numero: Invoice number
  • Data: Invoice date (dd/mm/yyyy or Excel date)

Numbers can be written in Italian format (2.049,18). You can find Excel examples in the example directory.

Questo modulo importa dati di fattura da un file Excel (.xlsx) in due modi:

  • Importa righe in una fattura: il bottone  Import xlsx  su una fattura o fattura fornitore in bozza aggiunge una riga per ogni riga del file. I prodotti sono cercati per codice e nome; prezzo, conto e imposte derivano dal prodotto, se il file non li indica.
  • Crea fatture: il menù Contabilità › Configurazione › Import Account Invoice crea fatture in bozza. Una riga con i dati del cliente apre una nuova fattura; le righe senza dati del cliente vi aggiungono righe.

Titoli di colonna riconosciuti:

  • Denominazione Cliente: Nome del soggetto
  • Partita Iva: Partita IVA (alle sole cifre viene anteposto IT)
  • Codice Fiscale: Codice fiscale
  • Codice: Codice prodotto
  • Nome: Descrizione della riga
  • Quantita: Quantità
  • Imponibile: Imponibile (riga con quantità 1)
  • Iva: Importo IVA; aliquota più vicina tra 0, 4, 5, 10, 22%
  • Numero: Numero fattura
  • Data: Data fattura (gg/mm/aaaa o data Excel)

I numeri possono essere scritti in formato italiano (2.049,18). Si possono vedere esempi nella cartella example.

Usage | Utilizzo

  • Open a draft invoice or vendor bill and click  Import xlsx ; choose the file and click  Import . Tick Dry-run to check the file without creating anything.
  • To create invoices, open Accounting › Configuration › Import Account Invoice, choose the file, the journal (sale or purchase) and the default invoice date. The result window lists the rows with problems (partner or product not found, more than one match).
  • Invoices are always created in draft: check and confirm them as usual.

  • Aprire una fattura o fattura fornitore in bozza e premere  Import xlsx ; scegliere il file e premere  Import . Selezionare Dry-run per controllare il file senza creare nulla.
  • Per creare fatture, aprire Contabilità › Configurazione › Import Account Invoice, scegliere il file, il registro (vendite o acquisti) e la data fattura predefinita. La finestra di risultato elenca le righe con problemi (soggetto o prodotto non trovato, più corrispondenze).
  • Le fatture sono sempre create in bozza: controllarle e confermarle come di consueto.
