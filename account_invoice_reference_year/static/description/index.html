Check duplicate vendor bill reference within the invoice year only

Controlla il riferimento duplicato della fattura fornitore solo nell'anno della fattura

Unknown description_img

When a vendor bill or refund is validated, standard Odoo rejects it if another bill/refund of the same supplier has the same vendor reference, whatever its date.

Italian suppliers restart their invoice numbering every year, so the same number comes back each year. This module rejects a vendor reference as duplicated only when it is found in the same calendar year as the invoice date. If the invoice date is empty, the current year is used.

Quando una fattura o nota di credito fornitore viene convalidata, Odoo standard la rifiuta se esiste un'altra fattura/nota di credito dello stesso fornitore con lo stesso riferimento, qualunque sia la data.

I fornitori italiani ricominciano la numerazione delle fatture ogni anno, quindi lo stesso numero si ripete ogni anno. Questo modulo considera duplicato il riferimento fornitore solo se presente nello stesso anno solare della data fattura. Se la data fattura è vuota, viene usato l'anno corrente.
