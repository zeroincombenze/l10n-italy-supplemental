Small technical tweaks to the Odoo core, so the core can stay as upstream:

* **Module description**: if the description of a module cannot be rendered,
  the Apps list shows *Error in Description* for that module instead of failing.
* **Base URL**: when the administrator logs in from a URL containing
  ``localhost`` (e.g. a local script using JSON-RPC), the ``web.base.url``
  system parameter is not overwritten.
* **RML report footer**: the vertical text in the left margin of RML reports
  reads *generated by Zeroincombenze(R)* instead of *generated by Odoo.com*.
  Existing companies are updated at install; the original text is restored at
  uninstall.
