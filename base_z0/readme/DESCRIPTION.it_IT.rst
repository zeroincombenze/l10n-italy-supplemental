Piccole personalizzazioni tecniche del core di Odoo, per lasciare il core
identico all'originale:

* **Descrizione modulo**: se la descrizione di un modulo non può essere
  visualizzata, l'elenco App mostra *Error in Description* per quel modulo
  invece di andare in errore.
* **URL base**: quando l'amministratore accede da un URL che contiene
  ``localhost`` (es. uno script locale via JSON-RPC), il parametro di sistema
  ``web.base.url`` non viene sovrascritto.
* **Piè di pagina report RML**: il testo verticale nel margine sinistro dei
  report RML riporta *generated by Zeroincombenze(R)* invece di
  *generated by Odoo.com*. Le aziende esistenti sono aggiornate
  all'installazione; il testo originale è ripristinato alla disinstallazione.
