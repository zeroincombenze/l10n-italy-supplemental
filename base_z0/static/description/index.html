Safe module description, base URL kept on localhost, RML footer

Descrizione modulo sicura, URL base invariato da localhost, piè di pagina RML

Unknown description_img

Small technical tweaks to the Odoo core, so the core can stay as upstream:

  • Module description: if the description of a module cannot be rendered, the Apps list shows Error in Description for that module instead of failing.
  • Base URL: when the administrator logs in from a URL containing localhost (e.g. a local script using JSON-RPC), the web.base.url system parameter is not overwritten.
  • RML report footer: the vertical text in the left margin of RML reports reads generated by Zeroincombenze(R) instead of generated by Odoo.com. Existing companies are updated at install; the original text is restored at uninstall.

Piccole personalizzazioni tecniche del core di Odoo, per lasciare il core identico all'originale:

  • Descrizione modulo: se la descrizione di un modulo non può essere visualizzata, l'elenco App mostra Error in Description per quel modulo invece di andare in errore.
  • URL base: quando l'amministratore accede da un URL che contiene localhost (es. uno script locale via JSON-RPC), il parametro di sistema web.base.url non viene sovrascritto.
  • Piè di pagina report RML: il testo verticale nel margine sinistro dei report RML riporta generated by Zeroincombenze(R) invece di generated by Odoo.com. Le aziende esistenti sono aggiornate all'installazione; il testo originale è ripristinato alla disinstallazione.

Configuration | Configurazione

No configuration is needed.

To never update web.base.url at login, whatever the URL, set the standard system parameter web.base.url.freeze to True.

Non serve alcuna configurazione.

Per non aggiornare mai web.base.url all'accesso, qualunque sia l'URL, impostare il parametro di sistema standard web.base.url.freeze a True.
