Filter BI analysis by document line description

Filtra le analisi BI per descrizione riga

Unknown description_img

This module adds the document line description in the BI analysis reports, so the end user can select the lines of sale orders and invoices by their name.

The new field Line Description is available in:

  • Sales Analysis (sale order lines)
  • Invoices Analysis (invoice lines)

The field is a plain text field: selection criteria are the standard Odoo ones, i.e. equal, not equal, contains, does not contain, is set, is not set.

Lines can also be grouped by their description.

Questo modulo aggiunge la descrizione della riga del documento nei report di analisi BI, così l'utente finale può selezionare le righe di ordini di vendita e fatture tramite il loro nome.

Il nuovo campo Descrizione riga è disponibile in:

  • Analisi vendite (righe ordine di vendita)
  • Analisi fatture (righe fattura)

Il campo è un semplice campo di testo: i criteri di selezione sono quelli standard di Odoo, cioè uguale, diverso, contiene, non contiene, è impostato, non è impostato.

Le righe possono anche essere raggruppate per descrizione.

Usage | Utilizzo

Open Sales > Reports > Sales or Invoicing > Reports > Invoices Analysis.

To search for a text contained in the line description, type the text in the search bar and select Search Line Description for: ...

To use another selection criteria, open Filters > Add Custom Filter, select the field Line Description, then select the criteria (equal, not equal, contains, does not contain, is set, is not set) and issue the value to search for.

Lines can be grouped by their description with Group By > Line Description.

Sales Analysis opens with the Sales filter active, which hides the quotations: lines of a quotation are found only after the Sales filter is removed from the search bar.

Aprire Vendite > Report > Vendite oppure Contabilità > Report > Analisi fatture.

Per cercare un testo contenuto nella descrizione della riga, digitare il testo nella barra di ricerca e selezionare Cerca Descrizione riga per: ...

Per usare un altro criterio di selezione, aprire Filtri > Aggiungi filtro personalizzato, selezionare il campo Descrizione riga, quindi scegliere il criterio (uguale, diverso, contiene, non contiene, è impostato, non è impostato) e indicare il valore da cercare.

Le righe possono essere raggruppate per descrizione con Raggruppa per > Descrizione riga.

L'analisi vendite si apre con il filtro Vendite attivo, che nasconde i preventivi: le righe di un preventivo si trovano solo dopo aver rimosso il filtro Vendite dalla barra di ricerca.
