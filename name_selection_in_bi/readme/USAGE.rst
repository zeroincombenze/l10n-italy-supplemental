Open *Sales > Reports > Sales* or *Invoicing > Reports > Invoices Analysis*.

To search for a text contained in the line description, type the text in the search
bar and select *Search Line Description for: ...*

To use another selection criteria, open *Filters > Add Custom Filter*, select the
field *Line Description*, then select the criteria (equal, not equal, contains,
does not contain, is set, is not set) and issue the value to search for.

Lines can be grouped by their description with *Group By > Line Description*.

|warning| Sales Analysis opens with the *Sales* filter active, which hides the
quotations: lines of a quotation are found only after the *Sales* filter is removed
from the search bar.
