This module adds the document line description in the BI analysis reports, so the
end user can select the lines of sale orders and invoices by their name.

The new field **Line Description** is available in:

* Sales Analysis (sale order lines)
* Invoices Analysis (invoice lines)

The field is a plain text field: selection criteria are the standard Odoo ones,
i.e. equal, not equal, contains, does not contain, is set, is not set.

Lines can also be grouped by their description.
