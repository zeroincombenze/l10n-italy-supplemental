Aprire *Vendite > Report > Vendite* oppure *Contabilità > Report > Analisi fatture*.

Per cercare un testo contenuto nella descrizione della riga, digitare il testo nella
barra di ricerca e selezionare *Cerca Descrizione riga per: ...*

Per usare un altro criterio di selezione, aprire *Filtri > Aggiungi filtro
personalizzato*, selezionare il campo *Descrizione riga*, quindi scegliere il
criterio (uguale, diverso, contiene, non contiene, è impostato, non è impostato) e
indicare il valore da cercare.

Le righe possono essere raggruppate per descrizione con *Raggruppa per >
Descrizione riga*.

|warning| L'analisi vendite si apre con il filtro *Vendite* attivo, che nasconde i
preventivi: le righe di un preventivo si trovano solo dopo aver rimosso il filtro
*Vendite* dalla barra di ricerca.
