Questo modulo aggiunge la descrizione della riga del documento nei report di analisi
BI, così l'utente finale può selezionare le righe di ordini di vendita e fatture
tramite il loro nome.

Il nuovo campo **Descrizione riga** è disponibile in:

* Analisi vendite (righe ordine di vendita)
* Analisi fatture (righe fattura)

Il campo è un semplice campo di testo: i criteri di selezione sono quelli standard
di Odoo, cioè uguale, diverso, contiene, non contiene, è impostato, non è impostato.

Le righe possono anche essere raggruppate per descrizione.
