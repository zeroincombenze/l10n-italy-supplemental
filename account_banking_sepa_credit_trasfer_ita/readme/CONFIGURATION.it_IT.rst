* Azienda: impostare l'**Identificativo della parte iniziante**, cioè il codice
  univoco CBI (CUC, 8 lettere o cifre). Può essere ridefinito nel modo di pagamento.
* Registro banca: il conto bancario deve avere un IBAN italiano; aggiungere il
  metodo *Sepa Credit Transfer ITA CBI* ai pagamenti in uscita.
* Modo di pagamento: creare un modo con questo metodo e il registro banca.
* Fornitore: il conto bancario deve avere un IBAN valido.

Se è installato un modulo che gestisce i conti di portafoglio, nel file viene
scritto come ordinante il conto principale del portafoglio.
