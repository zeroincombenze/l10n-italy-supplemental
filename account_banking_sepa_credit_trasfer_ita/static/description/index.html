SEPA Credit Transfer CBI file (Italy) for payment orders

File bonifici SEPA CBI (Italia) per le distinte di pagamento

Unknown description_img

Italian banks accept SEPA Credit Transfers in the CBI format (CBIPaymentRequest.00.04.00) instead of the standard ISO 20022 pain.001 file. This module adds the payment method Sepa Credit Transfer ITA CBI to the OCA payment orders: a payment order using it generates the CBI file, ready to be uploaded to the home banking.

The file is created by the Python library fintech.

Le banche italiane accettano i bonifici SEPA nel formato CBI (CBIPaymentRequest.00.04.00) invece del file standard ISO 20022 pain.001. Questo modulo aggiunge il metodo di pagamento Sepa Credit Transfer ITA CBI alle distinte di pagamento OCA: una distinta con questo metodo genera il file CBI, pronto per essere caricato sull'home banking.

Il file è creato dalla libreria Python fintech.

Configuration | Configurazione

  • Company: set the Initiating Party Identifier, which is the CBI unique code (CUC, 8 letters or digits). It can be overridden on the payment mode.
  • Bank journal: the bank account must be an Italian IBAN; add the payment method Sepa Credit Transfer ITA CBI to the outgoing payments.
  • Payment mode: create a mode with this method and the bank journal.
  • Supplier: the bank account needs a valid IBAN.

If a module providing wallet accounts ("conto di portafoglio") is installed, the main bank account of the wallet is written in the file as debtor.

  • Azienda: impostare l'Identificativo della parte iniziante, cioè il codice univoco CBI (CUC, 8 lettere o cifre). Può essere ridefinito nel modo di pagamento.
  • Registro banca: il conto bancario deve avere un IBAN italiano; aggiungere il metodo Sepa Credit Transfer ITA CBI ai pagamenti in uscita.
  • Modo di pagamento: creare un modo con questo metodo e il registro banca.
  • Fornitore: il conto bancario deve avere un IBAN valido.

Se è installato un modulo che gestisce i conti di portafoglio, nel file viene scritto come ordinante il conto principale del portafoglio.

Usage | Utilizzo

  • Validate the vendor bills with the SCT CBI payment mode.
  • Accounting › Payments › Payment Orders: create the order, or use Add to Payment Order on the bills.
  • Confirm the order and press Generate Payment File: the CBI XML file is attached to the order.
  • Upload the file to the home banking, then press File Successfully Uploaded.

  • Validare le fatture fornitore con il modo di pagamento SCT CBI.
  • Contabilità › Pagamenti › Ordini di pagamento: creare l'ordine, oppure usare Aggiungi a ordine di pagamento dalle fatture.
  • Confermare l'ordine e premere Genera file di pagamento: il file XML CBI viene allegato all'ordine.
  • Caricare il file sull'home banking, quindi premere File caricato con successo.
