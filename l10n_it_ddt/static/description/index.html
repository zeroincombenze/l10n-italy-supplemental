Choose how delivery notes (DDT) are grouped into invoices

Sceglie come raggruppare i DDT in fattura

Unknown description_img

Add to OCA l10n_it_delivery_note the choice of how delivery notes (DDT) are grouped together to make invoices, as in the former Odoo 10.0 l10n_it_ddt.

The grouping method is set on the customer and copied to the sale order:

  • One DDT - One Invoice: every delivery note has its own invoice
  • Billing Partner: delivery notes with the same invoice partner share the invoice
  • Shipping Partner: one invoice for each shipping address
  • By Sale Order: one invoice for each sale order
  • Code group: delivery notes shipped to partners with the same code group share the invoice

Aggiunge a l10n_it_delivery_note OCA la scelta di come raggruppare i DDT per fatturarli insieme, come nel vecchio l10n_it_ddt di Odoo 10.0.

Il metodo di raggruppamento si imposta sul cliente e viene copiato nell'ordine:

  • Un DDT - Una fattura: ogni DDT ha la sua fattura
  • Cliente fatturazione: i DDT con lo stesso intestatario fattura condividono la fattura
  • Destinazione: una fattura per ogni destinazione merci
  • Per ordine di vendita: una fattura per ogni ordine di vendita
  • Gruppo codice: i DDT con destinazione dello stesso codice gruppo condividono la fattura

Configuration | Configurazione

Set DDT invoicing group in the partner form, tab Invoicing. For Code group fill also DDT code group in the shipping partners. The sale order can override the value.

Impostare Gruppo fatturazione DDT nella scheda partner, tab Fatturazione. Per Gruppo codice compilare anche Codice gruppo DDT nelle destinazioni. L'ordine di vendita può modificare il valore.

Usage | Utilizzo

Select the delivery notes to invoice in the list view and run Create invoices: the invoices are made following the DDT invoicing group of each sale order.

Selezionare i DDT da fatturare nella vista elenco ed eseguire Crea fatture: le fatture sono create secondo il Gruppo fatturazione DDT di ogni ordine di vendita.
