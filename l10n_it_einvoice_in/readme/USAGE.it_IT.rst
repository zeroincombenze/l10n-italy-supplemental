* ☰ Contabilità > Acquisti > Fattura elettronica > [Creare]
* Caricare un file XML e fare click su [Salvare]

Se si utilizza il modulo *l10n_it_einvoice_send2sdi* i dati sono caricati
automaticamente alla ricezione da SdI.

* Visualizzare il contenuto della fattura facendo click su [Mostra anteprima]
* Fare click su [Azione] e su "Importa e-fattura" per creare una fattura in bozza oppure "Collega a fattura esistente" per collegare il file XML a una fattura già (automaticamente) creata

La videta mostra solo i file non registrati ma è possibile modificare il filtro.
